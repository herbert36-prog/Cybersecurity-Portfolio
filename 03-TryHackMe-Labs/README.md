# TryHackMe – Cybersecurity Practical Labs

## Project Overview

This section of my cybersecurity portfolio documents practical cybersecurity labs completed through TryHackMe.

The aim is to demonstrate my understanding of cybersecurity concepts through hands-on exercises, technical investigations and practical problem-solving.

Each write-up documents the purpose of the room, the concepts covered, the practical activities completed and the knowledge gained.

**Room:** [SOC L1 Alert Triage](https://tryhackme.com/room/socl1alerttriage)
