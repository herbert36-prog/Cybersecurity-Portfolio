## Overview

This room introduced me to the importance of logs in cybersecurity investigations and security monitoring.

I learned how logs record activities taking place across systems, applications and networks, providing useful information that security analysts can examine when investigating suspicious behaviour.

The practical exercises covered different log types, Windows Event Logs and web server access logs.

## Learning Objectives

- Learn how to analyse log information.
- Investigate Windows Event Logs.
- Analyse web server access logs.
